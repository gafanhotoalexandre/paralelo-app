Notas sobre a ferramenta
Como funciona
Uma explicação curta, sem manual interminável.
1. Prepare os documentos. Cole o JSON original e o atualizado, ou importe arquivos JSON pelos ícones de cada editor.
2. Escolha a comparação. Estrutural ignora mudanças comuns de valores escalares. Conteúdo também identifica diferenças entre valores.
3. Leia por diferença. O painel à direita organiza os pontos detectados. Clique em um item para inspecionar os dados e localizar sua propriedade.
4. Exporte. O resultado completo pode ser salvo como relatório Markdown.
Limites desta POC
A comparação é feita neste navegador com JavaScript, para demonstrar a experiência de interface. Não substitui o motor C# planejado, principalmente em casos como precisão numérica extrema, JSONs com chaves duplicadas e processamento de arquivos grandes. O algoritmo trata arrays por posição e compara amostras, não contratos OpenAPI.
